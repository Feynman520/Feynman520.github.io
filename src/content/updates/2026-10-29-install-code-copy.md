전자책 서점 앱에서는 책의 글자를 복사할 수 없어, 3-1 '클로드코드 설치하기' 2단계의 설치 명령을 붙여 넣기 어렵다는 문의를 받았습니다. 책에는 홈페이지에서 복사할 수 있다고 적었는데 그 자리가 없었습니다. 불편을 드려 죄송합니다.

- **설치 코드 페이지** — [설치 코드](/install/) 메뉴에서 윈도우·Mac 설치 명령을 [복사] 버튼 한 번으로 가져갈 수 있습니다.
- **모든 책 페이지** — 22권 책 소개 페이지마다 '설치 코드 복사' 칸을 더했습니다. 설치 명령은 시리즈 모든 권이 같습니다.
- **책의 프롬프트** — 레시피의 복붙 프롬프트는 각 권 자료실의 '프롬프트 치트시트(PDF)'에서 복사할 수 있습니다.
